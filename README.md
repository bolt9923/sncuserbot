# 🚀 Telegram Ultra Userbot

## Features
- Auto Tagging System
- Auto Reaction
- Clone Profile
- Pause / Resume / Stop

## Setup

1. Clone repo
git clone https://github.com/yourusername/telegram-ultra-userbot

2. Install
pip install -r requirements.txt

3. Setup env
cp .env.example .env

4. Run
python -m userbot.main
